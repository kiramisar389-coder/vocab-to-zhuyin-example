# vocab-to-zhuyin-example
this is a machine that fetches zhuyin, example sentences and translations all within the terminal, so I can finally close these perpetually-open browser tabs, instead keeping only my code editor open. 
I am a learner of Traditional, rather than simplified characters, which means I generally also prefer zhuyin to pinyin, and learn best when there is provided context. Hence, human-submitted, community verified example sentences are pulled from tatoeba.org, not machine-generated to avoid awkward translation.
